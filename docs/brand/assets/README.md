# Brand Assets

These SVG assets define the Phase 2 Current visual identity baseline.

- `current-mark.svg`: color mark for light backgrounds
- `current-mark-white.svg`: white mark for dark backgrounds
- `current-wordmark.svg`: color wordmark for README and docs
- `current-wordmark-white.svg`: white wordmark for dark backgrounds

The mark intentionally evolves the old circular myOS gesture into a calmer ocean-current form instead of replacing the project with an unrelated symbol.
