# Visual Identity

Current's visual identity should feel calm, modern, practical, and durable.

The name refers to **ocean currents**, not electrical current. The brand should suggest movement and momentum while preserving the feeling of a reliable base underneath.

## Identity goals

Current should communicate:

- movement without chaos
- momentum without hype
- stability beneath motion
- modern infrastructure
- developer-first capability
- minimalism and engineering discipline

Current should not feel:

- flashy
- cyberpunk
- AI-hype driven
- nautical-themed for its own sake
- like an electrical-current or lightning brand

## Mark

The Phase 2 mark is a circular current form. It intentionally preserves the old myOS logo's strongest gesture: a circular shape with internal motion.

Use the mark when space is tight or when Current appears near other project names.

## Wordmark

The wordmark combines the circular current mark with a simple system-sans "Current" word.

Use the wordmark for README headers, website headers, presentation covers, and other first-impression surfaces.

## Color palette

| Token | Hex | Use |
| --- | --- | --- |
| Abyss | `#0B1720` | Primary text, deep backgrounds |
| Current Teal | `#0E7490` | Primary mark stroke and active accent |
| Deep Current | `#164E63` | Secondary mark stroke, technical emphasis |
| Foam | `#E6F4F1` | Soft background tint |
| Surface | `#F8FAFC` | Light surfaces |
| Drift Gray | `#667085` | Secondary text |
| White | `#FFFFFF` | Dark-background marks and text |

Avoid neon gradients, purple-blue cyber palettes, and lightning/electric motifs.

## Typography

Prefer system fonts over custom brand dependencies:

- UI and prose: `Inter`, `ui-sans-serif`, `system-ui`, `Segoe UI`, `Arial`, sans-serif
- Code and terminal examples: `ui-monospace`, `SFMono-Regular`, `Menlo`, `Consolas`, monospace

This keeps Current aligned with upstream Linux pragmatism and avoids making branding a runtime dependency.

## Voice

Current should sound:

- clear
- practical
- upstream-respecting
- developer-first
- calm
- technically disciplined

Use phrases such as:

- image-native Linux
- container-first operating system images
- close to upstream
- practical defaults
- stable beneath motion
- reliable runtime
- clear image lanes
- AI-ready without AI bloat

Avoid phrases such as:

- AI OS
- autonomous OS
- Fedora killer
- Universal Blue competitor
- cyberpunk
- electric current
- lightning-fast by design

## Spacing and use

- Keep clear space around the mark at least equal to the inner stroke width.
- Do not stretch the mark or wordmark.
- Do not rotate the mark to create arbitrary wave imagery.
- Do not add glow, neon, chrome, or 3D effects.
- Do not use the mark to imply a separate commercial product from the open-source Current project.
